# Tafsir Mudah untuk Pelajar

Tafsir Al-Qur'an dengan bahasa sehari-hari untuk pelajar.

Situs: https://bondhan.github.io/tafseer/

## Struktur

- `tafsir/`: naskah per surah, format Markdown.
- `_layouts/`, `assets/`, `_config.yml`, `index.md`: tampilan situs (GitHub Pages dengan Jekyll, sumber dari branch `main`).
- `.claude/skills/humanizer/`: panduan gaya menulis yang dipakai untuk naskah.
